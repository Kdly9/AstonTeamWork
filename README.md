# AstonTeamWork

Учебный командный проект на Java по реализации сортировки объектов `ConventionVisitor`. 

## Возможности

* заполнение коллекции вручную, случайными данными или из файла;
* сортировка `QuickSort` по трём полям;
* компараторы по имени, типу билета и персонажу;
* запись данных в файл;
* многопоточный подсчёт вхождений элемента;
* собственная коллекция `CustomCollection`.

## Используемые технологии

* Java 21
* Maven
* JUnit 5

## Паттерны

* **Builder** — создание `ConventionVisitor`;
* **Strategy** — выбор способа заполнения коллекции.

## Формат файла

```text
Имя;ТИП_БИЛЕТА;ПЕРСОНАЖ
```

Пример:

```text
Иван;VIP;Наруто
Анна;OPEN_DATE;Луффи
```

## Тестирование

Тесты находятся в `src/test/java`.

Запуск тестов:

```bash
mvn test
```
